# Connect Android 3.0.1 (19): новые стандартные звуки

База — актуальный main `806507733e4f3d62331f74475b5b3090e6d0195a` (3.0.0/18). Его функциональные native-исходники совпадали с последней собственной сборкой Codex 3.0.0. Более поздняя история main сохранена. Один агент, один итоговый APK.

## Изменения

- `withConnectBuiltinSounds.js`, `assets/notification_sounds/`: оригинальные connect_ringtone.mp3 и connect_notification.mp3 включены в res/raw без обработки. SHA-256 проверяется до копирования и непосредственно внутри готового APK. FFmpeg полностью декодировал оба файла без ошибок: 44100 Гц, стерео; 30,040816 с / 481171 байт и 1,724082 с / 28103 байта соответственно. Громкость не менялась.
- В `ConnectCallAudio.kt` изменён только URI factory/fallback: raw/connect_call → raw/connect_ringtone. Пользовательский MediaStore URI остаётся первым вариантом; недоступный файл обрабатывается прежней диагностикой и новым fallback. Один владелец сигналов, зацикливание, DND/беззвучный режим, вибрация, остановка при завершении и короткие гудки/сигнал соединения не переписывались.
- В `android-sound-policy.ts`, `ConnectNativeSoundSettings.tsx`, `ConnectNativePush.ts` отсутствие настройки и старое soft выбирают ресурс connect_notification без расширения. По вашему явному выбору все неоднозначные старые soft переведены в новый default. Прежний soft доступен вручную как «Мягкий (прежний)», локально legacy-soft. Серверу передаётся совместимое soft: серверный enum не расширялся.
- Custom URI, bright/gentle, отключение уведомлений/вибрации и тишина сохраняются. «Сбросить» возвращает новый default, сохраняя отдельный переключатель «Без звука». Preview учитывает выбранную мелодию и встроенный вариант. Настройки native и embedded Android показывают «Connect — звонок/сообщение».
- Канал нового default — connect-native-messages-connect_notification-v6-<audible|silent>-<vib|still>. Custom/старые альтернативы сохраняют v5 ID. Существующие каналы не удаляются и не перезаписываются. При создании v6 переносятся читаемые ограничения старого soft-канала: блокировка/важность, DND, значок, видимость, свет, вибрация; системная тишина или собственный звук канала также сохраняются. Повторные push не создают каналы заново. Окончательное применение этих настроек ОС требует проверки на телефоне.
- Старые числовые raw-ID закреплены по APK 3.0.0: bright 0x7f110000, call 0x7f110001, gentle 0x7f110002, soft 0x7f110003. Новые notification/ringtone — 0x7f110007/8. Сохранены также три прежних library raw-ID. Закрепление выполняется реальным AAPT --stable-ids; одного public XML оказалось недостаточно, что было обнаружено проверкой APK до поставки. Это сохраняет числовые android.resource URI уже существующих каналов. Таблица ресурсов готового APK проверена.
- `withConnectSounds.js`: один preview-плеер, JS generation и нативный epoch отменяют запоздалую подготовку после stop/сворачивания/нового выбора/закрытия. При входящем действует прежняя остановка preview. Ограничитель только прослушивания увеличен с 10 до 60 секунд, чтобы проигрывать предоставленную 30-секундную запись целиком.
- Bridge-протокол/адаптер настроек допускают единственный дополнительный встроенный вариант legacy-soft; произвольные пути/URI через эту команду по-прежнему запрещены.
- Обновлены package.json, package-lock.json, app.json, APK-verifier и релизные проверки. Только основной Android build workflow заменён прямой сборкой текущего исходного кода: публичный файл ещё содержал установочный payload 2.2.7, способный откатить проект. Остальные workflow не менялись. YAML включает npm ci, hashes/decode, TS/JS/browser/JVM/lint/release и APK-verifier; сам по себе он не устанавливает новые исходники или MP3.

PWA и сервер не изменены: Supabase, API, push payload/доставка, Turnix/WebRTC, пропущенные, экран вызова, proximity, история и медиа оставлены прежними. Критические native-классы сверены побайтно с базой; у CallAudio изменена только ссылка на ресурс. 120 публичных файлов в APK, включая стикеры, темы и crypto, побайтно совпадают с предыдущим APK 3.0.0.

**Подпись Android Debug — прежний ключ, не production.** Сертификат совпадает с предыдущим собственным APK 3.0.0 (SHA-256 01c3072e92db381ff2b9cea1f2f1f9f9132719e385e98536f07e42318c71eec4). Production-ключ не предоставлен. Сертификат фактически установленного у вас APK здесь недоступен.

Распакуйте архив и откройте Connect.apk поверх установленного приложения. Пакет и пользовательские данные не сбрасываются. Установка поверх совместима при совпадении сертификата; само обновление на телефоне здесь не выполнялось. При конфликте подписи не удаляйте Connect: нужен исходный ключ установленной версии. PWA обновлять не требуется.

Для разработчика: ANDROID-SOURCE.patch — полный binary patch относительно указанной базы main, включая MP3. На этой базе: git apply --check ANDROID-SOURCE.patch, затем git apply ANDROID-SOURCE.patch. После сохранения исходников доступен включённый workflow .github/workflows/connect-android-final-build.yml. Ключи подписи в архив не включены.
